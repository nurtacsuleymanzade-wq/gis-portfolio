**Source of truth:** [portfolio-routing.json](./portfolio-routing.json). Last updated 2026-10-16.

## Bot operating rule

1. Read the Upwork job description. Identify the main deliverable, technology stack, and proof the client expects.
2. Select **one** most relevant live demo from the table; optionally add **one** complementary demo.
3. Do **not** attach unrelated samples just to increase the number of links.
4. Check that the selected GitHub Pages page loads and that interactive controls/media work before sending the proposal. A GitHub repository file alone does not prove public playback.
5. Say **self-directed concept/demo** for personal work; never call it a paid client project. Disclose synthetic data and simulated GPU functionality.
6. If no matching sample exists, use the [general portfolio](https://nurtacsuleymanzade-wq.github.io/gis-portfolio/) and propose a small targeted proof-of-concept; do not fabricate evidence.
7. On video jobs, check MP4 playback; if unavailable, use a still preview and clearly label it.
