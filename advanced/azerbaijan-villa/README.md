## What's actually built

The independent parametric architectural model has two floors, an L-shaped plan, a Baku-inspired limestone/bronze façade, separately editable window frames and glass, loggia arches, balcony balustrades, door, pergola, courtyard, paving, trees, pool and front gate. All meshes were reopened with trimesh to verify 455 named objects and nonempty geometry. It is a **geometric prototype**, not a measured professional architectural design and not a finished PBR/Cycles render.

## How the real cinematic render is intended to run

With Blender 4.x, a downloaded source GLB under `assets/` and a working GPU:

```bash
blender -b -t 8 --python blender/architectural_flythrough.py -- \
  --glb assets/villa_main_editable.glb --output outputs \
  --resolution 1920 1080 --samples 96 --render

# Only after 1440 PNG frames exist (frame_0001.png through frame_1440.png):
ffmpeg -framerate 24 -start_number 1 -i outputs/frames/frame_%04d.png \
  -c:v libx264 -crf 17 -preset slow -pix_fmt yuv420p -movflags +faststart outputs/villa_60s.mp4

ffprobe -v error -show_entries format=duration:stream=codec_name,width,height \
  -of default=noprint_wrappers=1 outputs/villa_60s.mp4
```

**IMPORTANT:** The provided Blender flythrough source is an unexecuted starting template, not a verified final rendering pipeline. It adds original landscaping elements and expects a building-only Thrixel GLB. For the prototype GLB already containing a landscaped plot, skip or adapt the script's duplicate-scene additions and asset scaling.
