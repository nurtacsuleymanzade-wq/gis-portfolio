165k-point WebGL map — Caucasus POIs + 3D terrain

165,235 real OpenStreetMap features (amenities, shops, tourism, places, historic sites, offices, leisure) across Azerbaijan, Georgia and Armenia, rendered client-side by MapLibre GL with filterable categories and a 3D terrain mode.

Open interactive map

Technique

  • Geofabrik PBF extracts parsed with GDAL/OGR in Python. Nodes plus area centroids, compacted to an 8 MB array (gzip-served).
  • MapLibre GL circle layer (GPU), data-driven colours and filters, click popups. Terrarium DEM for hillshade and 3D terrain. OpenFreeMap vector basemap. No API keys or paid services.

Who benefits / value

Who benefits. Tourism boards & travel startups (where are hotels, restaurants and attractions), retail & real-estate analysts (amenity density for site selection), municipalities (service coverage), and researchers (spatial accessibility studies). Value: a fast, token-free web map that handles 100k+ points in the browser and can be re-pointed at a client's own CSV/GeoJSON.

All outputs on this page were produced from open data with free software (Blender, PDAL, GDAL, OpenDroneMap, MapLibre GL, Three.js). Compute: a cloud Linux workstation with NVIDIA L4 GPUs.
