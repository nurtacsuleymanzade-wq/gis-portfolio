About

Maps with provenance

I specialize in QGIS cartography for tourism, regional planning, and academic research — with a focus on Azerbaijan and the South Caucasus. Every map is built from real vector and raster sources (OSM / Geofabrik, geoBoundaries, SRTM, curated tourism inventories), styled for print or web.

Clients get clear file packages (PNG / PDF / GeoPackage where needed), legend-ready layouts, and optional automation so the next edition is a script run, not a rebuild from scratch.
